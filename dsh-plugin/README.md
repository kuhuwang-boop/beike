# 备课工作台 · DeepSeek Harness 插件（dsh-beike）

让 DeepSeek 像一支 **AI 课件团队** 那样帮高校老师备课：读你的讲义、教材、旧课件 → 写教学设计（逆向设计 + BOPPPS）→ 做课件（含结构图、课堂提问）→ 写讲稿 → **逐条核对出处** → 浏览器里直接上课，或导出可编辑的 PPT。

课件和资料都保存在你自己的电脑上；插件自带一个「备课工作台」网页，用来预览、修改、核对和上课。

## 有什么

**给 AI 的 20 个工具**

| 工具 | 作用 |
|---|---|
| `beike_list` | 列出已有课次 |
| `beike_create_lesson` | 新建课次（课题、课程、课时、课型、授课对象、教学方法），自动带入资料库里的相关资料，返回备课须知 |
| `beike_add_material` | 添加资料：.docx / .pptx / .txt / .md 文件，或直接给文字（同时存进资料库） |
| `beike_read_materials` | 分段通读资料原文 |
| `beike_get_lesson` | 查看课次：备课须知（风格、课型、教学方法）、教学设计、每页内容、每页建议时长 |
| `beike_save_slides` | 保存课件：整套替换，或逐页修改，每次都可撤销 |
| `beike_save_plan` | 保存教学设计（学情、目标、重难点、误区、BOPPPS 过程、思政、板书、作业、反思） |
| `beike_set_lesson` | 改课题、课程、课时、课型、授课对象、教学方法、配色或学校模板 |
| `beike_profile` | 老师的备课风格、我的技能、教学方法库 |
| `beike_library` | 我的资料库：列出、搜索、推荐、读取、存入、加入课次 |
| `beike_image` | 配图：搜索免费图库、AI 生成（MiniMax H3-Image）、去掉 |
| `beike_video` | AI 教学短视频（MiniMax 海螺 H3），插在指定页后面 |
| `beike_course` | 课程与教案：新建课程（含教学大纲）、查看全貌与对齐检查、生成教学进度、复制到新学期、达成度报告、保存改进建议、导出教案集 |
| `beike_course_objectives` | 课程目标（布鲁姆层级、权重、大纲依据逐字核对）、毕业要求指标点、支撑矩阵 |
| `beike_session` | 每次课的 BOPPPS 教案：查看、保存（返回检查结果）、新增、为这次课做课件 |
| `beike_question` | 课程题库：按“目标 × 层级”出题、列出、删除 |
| `beike_paper` | 组卷（按目标权重自动组卷或手工挑题）、试题分析、导出 Word 试卷和答案 |
| `beike_check` | 课件体检 + 出处核对（不调用 AI） |
| `beike_export` | 导出 .pptx 课件或 Word 教案到工作区 |
| `beike_open` | 给出备课工作台网页地址 |

**一份备课技能 `beike`**：把“课件团队”的做法写成步骤和规则——共同原则（以资料为准、不编造）、教学设计、课型、教学方法落实、课件版式、13 种结构图选型、课堂提问、讲稿写法、配图与视频、质量督导与出处核对。AI 遇到备课任务时自动加载。

**备课工作台网页**（放在 DeepSeek Harness 的左侧边栏和右侧边栏里）

- 课次列表（按课程分组、可搜索）；新建时选课型、填授课对象，自动推荐资料库里的相关资料
- 课件预览与逐页编辑：改文字、新增 / 复制 / 删除 / 调整顺序、配图、撤销、版本历史
- 「只改这一页」和「常用指令」：一点就复制好指令，粘贴给 AI
- **样式**：36 套内置配色 + 上传学校 .pptx 模板（读取背景、校徽、色条、标题位置、主题色）；学校名称、横版 Logo、方形校徽
- **配图**：搜索免费图库（Openverse，填了 Key 还有 Pexels / Pixabay）、AI 生成、上传本地图片
- **AI 教学视频**：导入短片 / 原理演示 / 真实场景 / 故事情境，4–15 秒，可用某页配图做第一帧
- **体检与出处**：按讲稿估算课时；逐条对照你的资料，标出“有出处 / 部分有出处 / AI 补充”，单独列出资料里查不到的数字
- 资料管理：拖入文件或粘贴文字、查看并修改文字、从资料库添加
- **我的资料库**、**我的备课风格**（学生情况、语言风格、每页信息量、必有环节、常用案例、不要做的事）、**我的技能**、**新课次默认教学方法**、**常用指令**
- 教学设计：教学方法、授课对象、学情、目标、重难点、误区、BOPPPS 过程、思政、作业、板书、课后反思；下载 Word 教案、打印 / 存 PDF
- **上课**：浏览器全屏放映，翻页笔可用；A 显示答案、B 黑屏、P 演讲者视图（讲稿、下一页、计时、快慢提示）；投影窗口同步翻页；视频可直接播放
- 下载 PPT（16:9，文字可编辑，结构图是原生形状，讲稿和答案在备注里，带学校模板、校徽和教学视频）
- **课程与教案（逆向设计 / OBE）**：教学大纲 → 课程目标（布鲁姆层级、权重，大纲依据逐字核对）→ 毕业要求支撑矩阵（H/M/L）→ 一键生成全学期教学进度 → 每次课的 BOPPPS 教案（环节时长、学生活动、目标与检测）→ 题库与双向细目表 → 按目标权重自动组卷、导出 Word 试卷和答案 → 导入逐题成绩（Excel CSV）→ 难度、区分度、信度、分数段、课程目标达成度 → 持续改进建议 → 复制到新学期。每一环都有固定规则检查；教案可以一键生成课件，课件自动带上本次课的目标和教案
- AI 每改一次，网页自动刷新；手机上也能看

## 安装

需要：Node.js 20 或以上，DeepSeek Harness 0.2.x（`npx @deepseek-ai/dsh web` 能正常打开）。

把插件装进 `web` 配置（下面任选一种）：

```bash
# 1) 用安装包（.tgz）
dsh plugin --profile web add ./dsh-beike-1.4.0.tgz

# 2) 用解压后的文件夹（方便自己改代码；先在文件夹里执行一次 npm install）
dsh plugin --profile web add ./dsh-beike

# 3) 从 GitHub 安装（仓库地址换成你实际存放插件的仓库）
dsh plugin --profile web add github:你的账号/dsh-beike
```

> 没有全局安装 `dsh` 时，在命令前加 `npx @deepseek-ai/dsh`，例如 `npx @deepseek-ai/dsh plugin --profile web add ./dsh-beike-1.4.0.tgz`。

确认已装上：

```bash
dsh --profile web --dump-config | grep -A3 "dsh-beike"
```

然后启动：

```bash
dsh web
```

浏览器会打开 DeepSeek Harness，备课工作台已经放进侧边栏：

- **左侧边栏**：「备课工作台」入口（在 Plugins、Automation tasks 下面）。点开就在主区域显示完整的工作台。
- **右侧边栏**：在任意对话里打开右侧栏，点「+」新建标签，选「备课工作台」。一边和 AI 对话，一边看课件；AI 新建或修改了哪节课，右侧会自动切过去。

工作台也可以单独打开：**http://127.0.0.1:38127/beike/**（插件在本机开的网页，只允许本机访问）。

**桌面版 DeepSeek Harness**（Windows / macOS 安装版）同样适用：用下面的命令装进你正在使用的配置后，**完全退出再重新打开** DeepSeek Harness，左侧边栏就会出现「备课工作台」。Windows 用户可以直接双击仓库里的 `安装备课插件到DeepSeek.bat`，它会把插件装进本机所有 DeepSeek Harness 配置。

卸载：`dsh plugin --profile web remove dsh-beike`（课件和资料会保留在数据目录里）。

**命令行模式**（`dsh tui` 等没有网页界面的配置）也能用：同样用 `dsh plugin --profile <配置名> add ...` 安装；调用 `beike_open` 会给出本机网页地址。

## 怎么用

在 DeepSeek Harness 的对话框里直接说，例如：

- 用备课工作台，把 `D:\讲义\第三章 排序.docx` 做成一节 45 分钟的课件，课程是《数据结构》
- 继续完善《冒泡排序》：给每页写讲稿，再加两道课堂提问
- 核对《冒泡排序》的出处，把资料里找不到依据的内容改正
- 第 4 页改成结构图；整套换成“中国红”配色
- 把《冒泡排序》导出成 PPT 放到当前工作区

AI 做完会给你工作台链接。在网页里看效果、自己改几处、看「体检与出处」，然后点「上课」。

## 设置

在 `dsh --profile web --dump-config` 找到 `dsh-beike` 这一行，或在你的配置里覆盖：

```yaml
- insert:
    - id: beike
      name: dsh-beike
      config:
        dataDir: D:/备课数据      # 课件和资料保存位置，默认：用户主目录/备课工作台
        webPath: /beike           # 网页路径
        localPort: 38127          # 本机网页端口（桌面版侧边栏使用，一般不用改）
```

## 数据与隐私

- 课程与教案在 `<数据目录>/courses/<课程编号>.json`（目标、矩阵、教案、题库、试卷与成绩）。
- 个人设置在 `<数据目录>/profile.json`（备课风格、技能、常用指令、学校信息与模板），资料库在 `<数据目录>/library/`，API Key 在 `<数据目录>/secrets.json`（只在本机，不回传网页）。
- 每节课一个文件夹：`<数据目录>/lessons/<课次编号>/`，里面是 `lesson.json`（课件、教学设计）、`materials/`（资料提取出的文字）、`images/`（配图）。可以直接备份或拷贝到另一台电脑。
- 插件只在你使用配图 / 视频功能时联网：搜索图库（Openverse / Pexels / Pixabay）和调用 MiniMax。其余内容只经过你在 DeepSeek Harness 里配置的模型服务。
- 网页版沿用 DeepSeek Harness 的登录保护；本机网页只监听 127.0.0.1、只接受本机地址访问；所有修改请求都需要自定义请求头，其他网站无法伪造。

## 开发

```bash
npm install
dsh plugin --profile web add ./        # 以链接方式安装，改代码后重启 dsh web 即可
npm pack                               # 打包成 dsh-beike-<版本>.tgz 分发
```

目录：`index.js`（插件入口：工具、技能、网页挂载）、`lib/client.js`（浏览器端：左侧边栏入口、右侧边栏标签页）、`lib/`（课件规则、存储、资料提取、PPT 导出、网页接口）、`web/`（工作台网页与渲染内核）、`skills/beike/SKILL.md`（备课技能）。

渲染内核（`web/deckkit.js`、`web/diagram.js`）与网页版备课工作台共用；结构图版式目录改编自 pptx-compose-skill（MIT）。
